# 定位讨论结论（阶段 1 第五波）

> 组长撰写，2026-11-15。依据：`literature/novelty_report.md`、`reviews/novelty_check_1.md`、和 GPT 的定位讨论（thread `positioning`，1 轮，记录在 `reviews/discussions/positioning.md`；上限 3 轮，第 1 轮后分歧已清楚，未再继续以节省额度）。
> 注意：GPT 参与了本讨论，之后它对相关内容的审稿算"半独立"；本文件不发给 Gemini。GPT 对 CSA 等近作的定理解读自己标注为未验证。

## 1. 共识（组长与 GPT 一致）

1. **放弃原始的新颖性主张。** "扑克思维 + 博弈因子 + RL 调权重"和"在信号上加弃权层"都不能作为贡献。
2. **Z 要保守命名。** 筹码成本 / CGO / 异常换手称为"行为 / 持有人状态变量"，不称"对手私有信息的度量"；除非另有识别证据。
3. **方向 B 作为工作平台**：A 股日频、真实可成交性（T+1、涨跌停、停牌、成本）、按时间嵌套的评估。
4. **监控 ≠ 控制。** 任何理论陈述必须先分清三个对象：已出手交易的已实现亏损比例；入场时条件亏损概率的平均；下一笔 / 下一批交易的风险。对第二个可做鞅式推断；第三个需要额外假设；对任意序列同时保证低亏损和正覆盖率是不可能的。
5. **方向 A（机制）只作为有止损条件的小型试探**，不占主线。
6. **亏损频率只能是次要指标。** 高胜率可以伴随少数大亏；必须预先指定净组合表现、亏损幅度、换手、被弃交易的收益。

## 2. GPT 提出、组长接受的修正（比组长原方案更好）

1. **把核心研究问题改为"暴露调整后的归因"**，而不是又一个弃权层：
   *选择性交易何时真的改善了选股，何时只是改变了市场暴露、执行成本或资金利用率？* Z 是其中一个预先设定的检验对象。这样无论 Z 成功还是失败，问题都有意义。
2. **两个评价问题要分开**，因为匹配暴露会把"躲开坏日子"的择时价值按构造抹掉：
   - 部署后的策略是否改善了投资者结果？（同初始资金、同执行规则、同成本模型的可行策略对比 → 总价值）
   - 在给定暴露下，选择器是否改善了选股？（日内匹配入场数、投入资金、预设风险特征的对照 → 增量选股价值）
   - 归因基准：把候选门控的**资金配置时间表**套到未门控的基础组合上。
3. **Z 需要析因设计，不只是门控消融**：基础预测器含 / 不含 Z × 门控含 / 不含 Z，再加"用同样特征直接按期望净收益选股"。否则分不清"Z 有信息"和"Z 放在弃权层里才有用"。对照里要包含构造 Z 所用的价格历史和换手原料。
4. **"通用 GBDT 不会自动满足"不是合格的新颖性标准**——几乎任何强加的单调性都满足。需要的是能把机制与竞争解释区分开、且不是看了结果后挑出来的限制。
5. **卖压的符号不是无条件的**：处置效应卖压既可能预示亏损也可能预示反转收益，取决于入场时点和卖压是否持续。有用的限制应是"持有期 × 卖压持续性 × 流动性"的联合限制，而不是 CGO 的无条件符号。
6. **按日聚合解决了同日相关，但没解决重叠持仓下的延迟反馈。** 一条可行的保守证明路线：假设标签最迟 H 天到期、每日至多 M 笔入场 → 把入场日分成 H 条"车道"→ 每条车道内用有界鞅置信序列 → 在车道间分配错误概率。代价约 √H。**这只是可行起点，不是新颖性主张**；是否已被现有延迟反馈结果蕴含，未验证。A 股的停牌 / 涨跌停导致清算时间无界，是真正的额外困难。
7. **负面结果的表述要精确**：不说"收益主要来自降暴露"，而说"指定绩效指标上的表观改善，大部分可被暴露与成本感知的对照复现，剩余的增量选股价值在经济意义上很小"。负面结论要用预先设定的等价界，不能用"未拒绝零"。
8. **第一轮实验用紧凑基线集**：未门控配置、暴露时间表基准、分层随机选择、置信度过滤、已到期表现门控、通用亏损预测 ± Z、直接期望净收益选择。神经网络弃权方法（SelectiveNet、Deep Gamblers 等）后置。

## 4. 建议（组长）

**建议：调整方向后继续。不建议按原设想继续，也不建议放弃。**

- **主线（原方向 B 的升级版）**：论文问题定为"A 股日频选择性交易的增量价值从哪里来：选股、择时、还是暴露与成本？"，贡献是 (i) 可复现的评估协议（两个评价问题 + 暴露时间表归因 + 真实可成交性），(ii) 对持有人状态变量 Z 的预先设定的析因检验，(iii) 视核对结果而定的延迟 / 重叠反馈下的监控命题（可能只进附录）。
- **支线（方向 A，限时两周）**：最小的行为卖压模型，目标是一条关于持有期 × 卖压持续性 × 流动性的联合限制；推不出可识别预测就砍。
- **现实的投稿目标**（GPT 的定性判断，未验证）：ICAIF 或 Journal of Financial Data Science；有更强的一般性结果或经济机制时才考虑 Quantitative Finance。顶级 ML 理论会议和顶级金融期刊不现实。
- **下一步（关卡 1 通过后）**：先写两页的"估计对象与对照规范"；数据审计；小规模析因试点；同时核对 CSA / A-RCPS 的假设。

## 5. 调整方向的代价（必须让用户知道）

- 用户 idea 里的三样东西——扑克 / 博弈思想、博弈因子、强化学习——在调整后的论文里分别降为：动机、一个被检验的特征组、可选的对比基线。
- 论文可能以**负面或澄清性结论**收尾（"弃权的好处大部分来自暴露与成本"、"Z 没有增量价值"）。这样的论文可以发表，但不是"一个能赚钱的新方法"。
- "尽量不亏钱"在理论上只能做到对已出手交易亏损概率的**监控**，做不到保证。
