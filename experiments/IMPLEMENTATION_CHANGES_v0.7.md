## 0. 对实现者的要求（每个子任务都适用）

1. **不看结果。** 不计算、不查看任何特征与未来收益的关系、任何标签统计、任何策略绩效。测试只用合成数据和已落盘的 20 只试跑数据；干跑只报计数、残差、缺失率、取值范围。
2. 全量抓取在后台运行：**不启动、不停止、不干扰任何进程；不向任何数据源发请求；不读写抓取进程正在写的文件**（只读已落盘的试跑文件）。
3. 命令被权限系统拒绝时**停下来报告**，不换写法重试；不结束任何进程（包括自己误启动的，报告给组长处理）。
4. 改期望值之前先判断是引擎错还是期望错，写进报告（沿用引擎报告 §2.4 的做法）。每个修改项完成后重跑**全部**测试，不只跑新增的。
5. 参数一律进 `config.py`，并在 `PARAM_STATUS`（engine）/ `config.py` 注释（features）里标注"PLAN v0.7 裁决 X-n"。不留"实现者自选"而 PLAN 没写的参数；发现新的含糊处，列入报告，不自行决定。
6. 完成后更新各自的测试报告（新增一节"v0.7 修改"），写明：改了什么、新增测试数、全部测试通过数、仍未实现的部分。

优先级：**P0** = Freeze-1 之前必须完成且其他工作依赖它；**P1** = Freeze-1 之前必须完成；**P2** = 可在 Freeze-1 之后、Freeze-2 之前完成或依赖尚不存在的输入。
