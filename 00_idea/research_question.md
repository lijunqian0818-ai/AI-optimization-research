## 研究问题
**主问题（RQ）：** 在不完全信息的股票市场中，一个处于信息劣势的交易者能否借鉴扑克式的不完全信息博弈思维——"根据公共信息推断自己是否处于劣势，没有把握就弃牌"——在传统多因子信号之上构造一个出手 / 弃权决策层，使其在可证明的意义下降低单笔亏损概率和下行风险，并且在 A 股真实数据上成立？

**子问题**
- RQ1（形式化）：扑克中的"弃牌"在交易中对应什么数学对象？候选：带弃权选项的序贯决策（selective prediction / reject option），其中弃权依据是对"对手方信息优势"的估计（博弈因子）。
- RQ2（理论）：在什么假设下，叠加弃权层后的策略相对于"有信号就出手"的多因子基线，亏损概率 / 下行风险有可证明的上界？覆盖率与风险之间的权衡是什么形式？
- RQ3（方法）：博弈因子怎么从可观察的公共信息构造（筹码成本分布、换手率异常、相对他人成本等）？因子权重与弃权阈值如何学习（强化学习或更简单的在线 / 校准方法）？
- RQ4（实证）：在 A 股日频、含成本、样本外的回测中，弃权层是否真的降低亏损概率和回撤？代价（错过的收益、覆盖率下降）多大？相比简单基线（波动率过滤、置信度阈值）是否有增益？

## 核心假设（待检验，不是结论）
- H1. 多因子信号的错误在时间和截面上不均匀；存在可由公共信息估计的状态变量（"博弈因子"），在该变量指示信息劣势时，信号出手的条件亏损概率显著更高。
- H2. 基于该状态变量的弃权规则可以在给定覆盖率下降低亏损概率 / 下行风险，并且有不依赖具体因子形式的理论保证（如分布无关的风险控制）。
- H3. 博弈因子带来的增益不能被"模型置信度阈值"或"波动率过滤"等非博弈基线完全解释。

## 预期贡献
**理论（1–3 条）**
1. 把"扑克式弃牌"形式化为带弃权的交易决策问题，给出亏损概率 / 下行风险的保证以及覆盖率–风险权衡。
2. （视文献而定）刻画信息劣势交易者的最优出手区域：何时"不出手"是最优反应。
3. （可选）权重 / 阈值学习算法的收敛或遗憾界。

**应用（1–3 条）**
1. 一个叠加在多因子模型之上的"博弈因子 + 弃权层"框架及开源实现。
2. A 股日频样本外回测：亏损概率、最大回撤、CVaR、覆盖率、收益，对比多因子基线与非博弈弃权基线，≥3 个随机种子，含交易成本。
3. 消融：博弈因子、弃权层、学习方法各自的贡献；如实报告不利结果。

## v2 修订（2026-11-15，GPT 讨论第 1 轮后；记录见 `reviews/discussions/research-question.md`）

组长接受了 GPT 的以下意见，v2 以本节为准，上面 H1–H3 与"预期贡献"中与之冲突处作废：

**假设改写（可证伪版本）**
- H1′（可预测性，实证）：设 Y=1 表示一笔按预先固定的执行与退出规则计算的净亏损交易；B = 基础信号、校准置信度、波动率、流动性、市场状态；Z = 候选"逆向选择代理变量"（筹码成本、换手异常等）。在 B 上加入 Z 能改善样本外对 Y 的预测（proper scoring rule）以及预设覆盖率下的交易决策。
- H1-机制（单列，目前**未验证**）：Z 确实度量"信息劣势"。日频公共数据无法直接识别对手私有信息；只有从显式模型推出方向性预测并通过检验后才可主张。
- H2a（实证）：在匹配覆盖率与可比资金暴露下，弃权层降低已出手交易的亏损概率。
- H2b（定理目标）：在明确陈述的随机假设下，某个校准 / 监控程序控制一个精确定义的"已选交易风险"量。必须允许零覆盖率或给出可行性假设。
- H3′（增量价值）：相同信息、模型容量、调参预算、执行假设下，机制导出的构造相对"通用亏损预测过滤器（含同样的 Z）"改善样本外风险–覆盖率前沿。若通用模型同样好，结论只能是"Z 是有用的预测变量"，不能说博弈决策规则更优。

**理论目标收窄**
- 理论保证的对象是**已选交易的亏损概率 / 交易级下行损失**；**最大回撤和组合 CVaR 不作为定理目标**，只作为实证指标（它们依赖仓位、重叠持仓、相关性）。
- 不主张无条件的"分布无关"前瞻保证。候选路线：对已选交易风险的序贯（鞅）监控，不需要可交换性；前瞻保证需要显式的漂移假设并把漂移项写进界里。同日多只股票不能当独立序贯样本，需按日聚合。
- "博弈"要成为实质，需要一个最小的知情交易者模型（玩家、信息集、行动、收益），推出至少一条可检验的限制（如"给定基础 alpha，逆向选择暴露越高，入场所需 alpha 越高"——这个单调性本身也要推导，不能假定）。

**方法**
- 起点是简单的监督 / 校准弃权层；**强化学习降为可选**：除非行动确实改变未来状态或约束，否则 RL 只增加估计难度。
- 必须比较的基线：未过滤多因子策略；匹配覆盖率的随机稀疏化；基础得分 / 校准置信度阈值；波动率、流动性、市场状态过滤；通用监督亏损预测器（meta-labeling），含与不含 Z；期望净收益与下行风险过滤；现金缩放与波动率目标基线；滚动 selective-risk 校准。

**实验设计补充**
- 时间顺序稳健性优先于随机种子：嵌套的按时间训练 / 校准 / 测试、重叠标签清除（purging）、最终冻结留出集、按日期聚类的不确定性估计、分市场状态 / 流动性 / 时段报告、成本与涨跌停不可成交的敏感性。
- 建模之前先做数据审计（时点成分股、退市股、公司行为、可成交性）；免费数据能否满足，**未验证**。

## v3 调整方向（2026-11-15，关卡 1 用户决定"调整方向后继续"）

**以本节为准；与上文冲突处作废。** 依据：`literature/positioning.md`、`reviews/novelty_check_1.md`。

**主问题（RQ-v3）：** 在 A 股日频、只做多、T+1、含成本与真实可成交性的条件下，叠加在多因子信号之上的选择性交易（出手 / 弃权）带来的表观改善，来自哪里——选股、择时，还是市场暴露、执行成本与资金利用率的变化？持有人状态变量 Z（筹码成本 / 资本利得悬挂、异常换手等）对此有没有增量价值？

**两个评价问题（分开回答）**
- Q-总价值：部署后的策略是否改善投资者结果？对照是同初始资金、同执行规则、同成本模型的可行策略。
- Q-选股：在给定暴露下，选择器是否改善了选股？对照是日内匹配入场数、投入资金、预设风险特征的选择；归因基准是把候选门控的资金配置时间表套到未门控的基础组合上。

**假设（预先设定，可证伪）**
- H-A（归因）：已有弃权方法（置信度过滤、已到期表现门控、通用亏损预测）在指定绩效指标上的表观改善，大部分可被暴露与成本感知的对照复现。用预先设定的等价界判断"增量选股价值在经济意义上很小"。
- H-Z（析因）：Z 的价值按 2×2 析因检验——基础预测器含 / 不含 Z × 门控含 / 不含 Z，再加"同样特征直接按期望净收益选股"。对照中包含构造 Z 所用的价格与换手原料。
- H-T（理论，待核对后才承诺）：在标签最迟 H 天到期、同日多股任意相关、重叠持仓的交易流上，对"入场时条件亏损概率的平均"给出时间一致的监控界。只在核对 CSA / A-RCPS / 延迟反馈文献后确认不是已知推论时才作为定理；否则放附录。
- H-M（机制支线，限时两周）：最小的行为卖压模型能否推出关于持有期 × 卖压持续性 × 流动性的、能与竞争解释区分的联合限制。止损标准：推不出可识别的预测。

**措辞约束**
- Z 称为"持有人状态 / 行为变量"，不称"对手私有信息的度量"。
- 不写"首次把弃权 / 扑克思维用于股票交易"；扑克只作动机。
- 理论只说"监控"，不说"保证不亏"。亏损频率是次要指标；主要指标预先指定为净组合表现、亏损幅度、换手、被弃交易的收益。
- 强化学习是可选对比基线，不是卖点。

**目标会议 / 期刊（暂定）：** ACM ICAIF 或 Journal of Financial Data Science。

## v4（2026-11-15，与 `experiments/PLAN.md` v0.4 对齐；以本节为准，v3 中与之冲突处作废）

修订原因：ARS 方法审查（`reviews/plan_methodology_ars_1.md`，必改项 R1–R3）指出 v3 的问题陈述比确认性检验能支撑的更宽，且与实验方案脱节。本节只主张检验能支撑的内容。**状态：组长起草，待用户在关卡 2 确认。**

### 研究问题
在 A 股日频、只做多、T+1、含成本的**事后合成成交**回测中（免费日线数据，无集合竞价时间戳）：
- **RQ-1（确认性）**：叠加在多因子基础信号之上的出手 / 弃权门控，在**同一批提名内**，相对于匹配下单机会的分层随机选择，是否带来经济上不可忽略的选股价值？
- **RQ-2（确认性）**：把两组变量加入门控，是否改变这一批次内选股价值？两组变量是：Z_H（持有人状态：资本利得悬挂、筹码分布、异常换手）与 Z_O（其他可识别参与者的可观察动作：龙虎榜、大宗交易、实际增减持；只用免费数据）。
- **RQ-3（描述性，不作确认性主张）**：门控策略相对未门控基础组合的可加 P&L 差，按暴露时间表、构成、成本三项如何分解；部署层面的期末财富与回撤如何。

### 问题的每一部分对应什么证据

| 问题中的说法 | 估计对象 | 证据地位 |
|---|---|---|
| 批次内选股价值（门控 vs 同一提名内分层随机） | θ_sel：每单净收益减去同一提名内分层随机选择的精确期望 | **确认性**（C1、C2：等价检验） |
| Z_H 对门控的增量 | 门控含 Z_H 与不含 Z_H 的 θ_sel 之差 | **确认性**（C3：差异检验） |
| Z_O 对门控的增量 | 门控含 Z_O 与不含 Z_O 的 θ_sel 之差 | **确认性**（C4：差异检验；若 Z_O 数据审计不通过则撤出，族大小由 4 降为 3） |
| 暴露时间表 / 择时的贡献 | Lemma 3 的暴露时间表项（隔夜 / 日内分区间可加归因） | 描述性 |
| 成本的贡献 | Lemma 3 的成本差项 | 描述性 |
| 部署后的总价值 | 期末财富、CAGR、回撤等 | 描述性 |
| 已出手交易亏损概率的监控区间 | r_T^entry 的时间一致区间（Theorem 1，合成成交流） | 描述性：只用于说明"交易流能承载的证据上限"，不用于比较方法 |

多重比较：C1–C4 构成一个 Holm 族（m = 4，或 3）。其余一律为探索性或描述性，论文中不得用确认性措辞。

### 假设（与 PLAN v0.4 的确认性检验一一对应）
- **H-A1（C1）**：置信度过滤门控的 θ_sel 在预设等价界内（经济上可忽略）。
- **H-A2（C2）**：不含 Z 的通用亏损预测门控的 θ_sel 在预设等价界内。
- **H-ZH（C3）**：在门控中加入 Z_H 使 θ_sel 发生变化（双侧）。
- **H-ZO（C4）**：在门控中加入 Z_O 使 θ_sel 发生变化（双侧）。
- v3 的"表观改善大部分来自暴露与成本"**不再作为假设**：它涉及的暴露与成本项没有确认性检验，只作描述性报告。
- **H-T**：不是待检验的假设。Theorem 1 / Proposition 2 作为方法性结果提供监控区间与证据上限的说明。
- **H-M（机制支线）**：暂停。价格压力工作表推不出可与普通流动性压力区分的联合限制；去留待用户决定。

注意：等价界（目前占位为每单 ±5bp）与等价检验的可达功效尚未确定；方法审查认为在该界下功效很可能不足（R6）。在看到任何开发期结果之前，必须决定 C1 / C2 是确认性等价检验还是预先声明的估计目标。

### 每种结果下论文的贡献

| 结果 | 能说什么 | 不能说什么 |
|---|---|---|
| C1 / C2 等价成立 | 在该合成成交设定与等价界下，这两类弃权门控的批次内选股价值经济上可忽略；其表观改善应从暴露与成本的描述性分解中去找 | 不能说"弃权无用"；不能推广到其他市场、频率或真实可执行成交 |
| C1 / C2 未能证明等价，且区间落在等价界之外 | 描述性地报告：估计的批次内选股价值及其区间落在界外（方向与大小）；等价检验本身不"证明存在效应" | 不能把未通过等价检验写成"证明了有选股价值"；不能说来源是"信息劣势判断" |
| C1 / C2 按预先规则降为"仅估计"（设计阶段功效不足） | 报告 θ_sel 的点估计与区间作为预先声明的估计目标，不做等价结论 | 不能事后再把它当作确认性检验解读 |
| C3 / C4 显著 | 该组变量作为门控特征带来增量选股价值（管线特征干预意义上） | 不能说它度量了对手的私有信息；不能主张博弈论机制 |
| C3 / C4 不显著且未证明等价 | "未检测到改善"，并报告区间与功效 | 不能说"没有增量" |
| 无定论（功效不足） | 报告估计值与区间、功效前检结果，以及单一市场历史能承载的证据上限（Prop 2 的有效样本量解释 + 实测相关结构） | 不能把无定论写成阴性或阳性结论 |

**不依赖任何结果的贡献**：(i) 一套时点安全、可复现的 A 股选择性交易评估协议（合成成交的明确定义、基准价记账、台账对账、匹配下单机会的随机对照、冻结的逐年部署算法、全管线零假设模拟）；(ii) "已出手交易风险"的精确估计对象与延迟到期标签下的监控区间及其下界（定位为已有工具的适配，放附录）；(iii) 持有人状态与他人动作两组变量在门控中的预先设定检验的完整报告，含阴性与无定论结果。
